# أنيسك | Anisk

## تشغيل محلي (للتجربة على الكمبيوتر)
```
npm install
npm run dev
```

### تفعيل "اسأل أنيسك AI" محليًا (اختياري لو عايزة تجربيها وانتِ بتطوّري)
1. اعملي حساب على console.anthropic.com واحصلي على مفتاح API (Get API Key).
2. اعملي ملف جديد اسمه `.env` في جذر المشروع (بجانب `package.json` بالظبط)، وحطي فيه سطر واحد:
   ```
   ANTHROPIC_API_KEY=مفتاحك_هنا
   ```
3. أعيدي تشغيل `npm run dev`.

ملف `.env` ده متضمّن في `.gitignore` أصلًا، يعني مش هيترفع على GitHub أبدًا — آمن.

## نشر حقيقي (خطوة تخلي التطبيق يشتغل على أي موبايل)
أسهل طريقة مجانية: Vercel

1. اعملي حساب مجاني على vercel.com (تقدري تسجّلي دخول بحساب GitHub مباشرة).
2. ارفعي هذا المجلد على GitHub (repo جديد)، أو استخدمي "Vercel CLI" لو مبرمج بيساعدك:
   ```
   npm i -g vercel
   vercel
   ```
3. Vercel هيبني المشروع تلقائيًا (Framework: Vite) ويديكي رابط دائم زي:
   `https://anisk.vercel.app`
4. افتحي الرابط من متصفح الموبايل (Chrome على أندرويد بالذات) — هيظهر تلقائيًا اقتراح
   "تثبيت التطبيق" (Install App)، مش مجرد "إضافة اختصار". لما تثبّتيه:
   - هيظهر كأيقونة تطبيق حقيقية في قائمة التطبيقات
   - هيفتح بدون شريط المتصفح (شاشة كاملة)
   - هيشتغل جزئيًا بدون إنترنت (القرآن كامل محفوظ محليًا)
   - البيانات (الصلوات، الأذكار، التقدّم، المحفوظات) هتتحفظ فعليًا على الجهاز (localStorage) —
     محدش هيشوفها غير المستخدمة نفسها على نفس الجهاز والمتصفح.

هذا "PWA حقيقي" — مش اختصار لصفحة ويب، تطبيق مثبَّت فعليًا. على آيفون (Safari) التثبيت أبسط شوية
(زر "إضافة إلى الشاشة الرئيسية" لكن بواجهة تطبيق كاملة الشاشة برضو).

## تفعيل "اسأل أنيسك AI" بعد النشر على Vercel — خطوة إضافية مطلوبة
1. اعملي حساب على console.anthropic.com واحصلي على مفتاح API (Get API Key) — لو عملتيه
   بالفعل للتجربة المحلية، استخدمي نفس المفتاح.
2. من لوحة تحكم مشروعك على Vercel: **Settings → Environment Variables**.
3. أضيفي متغيّر باسم `ANTHROPIC_API_KEY` وقيمته المفتاح اللي جبتيه.
4. اعملي **Redeploy** للمشروع (من تبويب Deployments → آخر نشر → Redeploy).

المفتاح ده بيفضل على السيرفر بس (جوه `api/ai.js`) ومحدش يقدر يشوفه من كود الموقع —
ده السبب في وجود الخطوة دي أصلًا بدل ما أحط المفتاح في الكود مباشرة (ده كان هيبقى غير آمن
لأي حد يفتح الموقع).

بدون المفتاح ده، باقي التطبيق (المصحف، الصلاة، الأذكار، الصوت) هيشتغل عادي تمامًا —
بس شاشة "اسأل أنيسك AI" هتوريكي رسالة واضحة تقولك إن المفتاح ناقص، بدل ما تفشل بصمت.

## لو عايزة تطبيق فعلي على Google Play / App Store
ده خطوة إضافية بعد النشر، عن طريق أداة اسمها **Capacitor**:
```
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init
npx cap add android
npm run build
npx cap sync
npx cap open android
```
ده هيفتح المشروع في Android Studio، ومنه تقدري تعملي بناء ملف APK حقيقي تقدري تنزّليه
مباشرة أو ترفعيه على متجر Google Play. ده محتاج تثبيت Android Studio على الكمبيوتر
(أداة مجانية من جوجل)، وده الجزء اللي محتاج جهاز حقيقي أو مبرمج يساعد فيه — الكود جاهز
تمامًا لهذه الخطوة.
